Seu trabalho reúne estudos de semiótica, estruturas linguísticas e relações entre linguagem e experiência humana, buscando integrar abordagens existentes em um projeto computacional. Sua contribuição inclui concepção, trabalho prático, decisões de desenvolvimento e revisão crítica.
